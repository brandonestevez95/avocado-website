# avocados.brandonestevez.com

Companion site for "Ripe for Disaster: Where Supply Chains Break" (Fall 2026 Spooky Research Slam, NC State ARE).
Static HTML, deployed via Cloudflare Workers static assets. Design language borrowed from www.brandonestevez.com.

- `index.html` — the whole site (CSS + JS inline)
- `assets/slides/` — slide images exported from the deck PDF
- `assets/Ripe-for-Disaster-...pdf` — full deck download

Embedded ArcGIS Instant Apps: Avocado Production (2014 vs 2024) and Homicide vs. Deforestation.
